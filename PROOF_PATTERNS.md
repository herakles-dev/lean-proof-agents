# PROOF_PATTERNS.md — compounding proof memory

Goal-shape → the tactic/lemma that worked. **Append a row every time a proof lands.** The prover
(`/prove`, `lean-prover`) consults this first — the more we prove, the faster we prove.

## Recurring recipes

| Goal shape | Recipe | Seen in |
|---|---|---|
| `∑_{i<n} f i = <closed form>` | `induction n with \| zero => simp \| succ k ih => rw [Finset.sum_range_succ, ih]; ring` | C0003, C0004, C0005 |
| ℕ closed form with division | reformulate **division-free** (`s * d = …`), prove that, avoid `ℕ` `/` and `-` | C0003, C0005 |
| real inequality `f ≤ g` | `nlinarith [sq_nonneg (a - b), …]` — feed the key nonneg square(s) as hints | C0006 |
| `Irrational (√k)` | `Nat.Prime.irrational_sqrt` / `irrational_sqrt_two` | C0001 |
| "there are infinitely many …" | `Nat.exists_infinite_primes`, `Set.Infinite`, `Nat.infinite_setOfPred_prime` | C0002 |
| goal has a single matching lemma | `scripts/lean-suggest.sh "<binders> : <goal>"` → paste the `exact …` | (tooling) |

## Tactic reflexes

- ℕ/ℤ arithmetic goal → **`omega`** first.
- ring/field equality → **`ring`** (use `push_cast`/`field_simp` first if casts/denominators).
- inequality → **`nlinarith`** with `sq_nonneg`/`mul_pos` hints; monotonic step → **`gcongr`**.
- concrete numerals → **`norm_num`**; decidable on small data → **`decide`**.
- "surely a lemma exists" → `lean-suggest.sh` (by goal) or `mathlib-search.sh` (by name).

## Gotchas logged

- `ℕ` subtraction/division **truncate** — never state a theorem that relies on them naively; multiply
  through instead.
- Deprecations surface as build warnings (e.g. `Nat.infinite_setOf_prime` → `Nat.infinite_setOfPred_prime`);
  fix to the current name to keep builds warning-clean.
- Importing all of `Mathlib` (via `MathProof.Basic`) keeps every lemma in scope; builds stay ~5s
  because Mathlib comes from the prebuilt cache.
