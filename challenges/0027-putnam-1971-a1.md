## Problem

Given any 9 points with integer coordinates in 3-space, show that the open segment joining
some pair of them contains a point with integer coordinates (equivalently, some pair has an
integer-coordinate midpoint). (PutnamBench `putnam_1971_a1`; verified to have no existing
Mathlib `Archive` formalization — an unaided ceiling-test target.)

## Formal statement

```lean
theorem putnam_1971_a1
    (S : Set (ℤ × ℤ × ℤ)) (hS : S.ncard = 9)
    (L : (ℤ × ℤ × ℤ) × (ℤ × ℤ × ℤ) → Set (ℝ × ℝ × ℝ))
    (hL : L = fun ((a, b, c), (d, e, f)) =>
      {(t * a + (1 - t) * d, t * b + (1 - t) * e, t * c + (1 - t) * f) | t ∈ Ioo (0 : ℝ) 1}) :
    ∃ x y z : ℤ, ∃ P Q : ℤ × ℤ × ℤ, P ∈ S ∧ Q ∈ S ∧ P ≠ Q ∧
      ((x : ℝ), (y : ℝ), (z : ℝ)) ∈ L (P, Q)
```

## Notes

DEPTH-loop solve (`proof-strategist` plan + ledger (not committed), assembled by
`lean-prover`). Three-leaf decomposition:

1. **Pigeonhole** the 9 points of `S` into the `2×2×2 = 8` parity classes of `(ZMod 2)³` via
   `Set.exists_ne_map_eq_of_ncard_lt_of_maps_to` (`8 < 9`) to get distinct `P ≠ Q ∈ S` with equal
   parity image.
2. **Per-coordinate parity equality ⇒ integer midpoint witness**: `(u : ZMod 2) = (v : ZMod 2) →
   ∃ k, u + v = 2 * k`, via `((u - v : ℤ) : ZMod 2) = 0` and
   `ZMod.intCast_zmod_eq_zero_iff_dvd`.
3. **Membership at `t = 1/2`**: unfold `hL`, supply `t = 1/2 ∈ Ioo 0 1`, and close the `Prod`
   equality with `ext <;> dsimp <;> linarith` from the three midpoint witness equations
   (`exact_mod_cast`).
