# Challenge 0006 — Two-variable AM–GM (2ab ≤ a² + b²)

- **Module:** `MathProof/Challenges/C0006Amgm.lean`
- **Theorem:** `MathProof.Challenges.C0006Amgm.two_mul_le_add_sq`
- **Status:** ✅ SOLVED

## Problem

Prove `2ab ≤ a² + b²` for all real `a, b` (equivalently `(a−b)² ≥ 0`).

## Formal statement

```lean
theorem two_mul_le_add_sq (a b : ℝ) : 2 * a * b ≤ a ^ 2 + b ^ 2
```

## Notes

First inequality (real-analysis flavour). `nlinarith [sq_nonneg (a - b)]`. Clean axioms, no `sorry`.
Proved directly rather than through a subagent.
