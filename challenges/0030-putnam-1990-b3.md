## Problem

Let `S` be a set of `2×2` matrices with natural-number entries, each entry a perfect square
`≤ 200`. Prove that if `|S| > 50387` then `S` contains two distinct matrices `A ≠ B` that
commute (`AB = BA`).

## Formal statement

```lean
theorem putnam_1990_b3
    (S : Set (Matrix (Fin 2) (Fin 2) ℕ))
    (hS : ∀ A ∈ S, ∀ i j : Fin 2, (∃ x : ℤ, A i j = x ^ 2) ∧ A i j ≤ 200) :
    (S.encard > 50387) → (∃ A ∈ S, ∃ B ∈ S, A ≠ B ∧ A * B = B * A)
```

## Proof

Pigeonhole via `Set.exists_ne_map_eq_of_encard_lt_of_maps_to`. Each entry, being a perfect
square `≤ 200`, is one of 15 values `{0,1,4,…,196}`; `idx = min (Nat.sqrt ·) 14 : ℕ → Fin 15`
recovers the root (`idx_val_sq : (idx n)² = n` on valid entries), so a matrix is coloured by its
4-tuple of indices `(p,q,r,s) ∈ Fin 15⁴` (`|·| = 50625`).

Two always-commuting cliques get merged to single "sink" colours to push the palette below the
threshold `50388`:

- **diagonal** (`q=0 ∧ r=0`, i.e. `M₀₁=M₁₀=0`) → sink `(0,0,0,0)`;
- **pencil** (`r=0 ∧ p=s`, i.e. `M₁₀=0 ∧ M₀₀=M₁₁`, form `aI+bE₁₂`, `E₁₂²=0`) → sink `(0,1,0,0)`;
- **else** → its own tuple, which lands in `{r≠0} ∪ {r=0 ∧ q≠0 ∧ p≠s}`.

Palette `tgt = tA ∪ tB ∪ tC` with `|tA| = 15·15·14·15 = 47250` (`r≠0` product),
`|tB| ≤ (15²−15)·14 = 2940` (`Finset.offDiag_card` + `card_image_le`), `|tC| ≤ 2` (sinks):
`|tgt| ≤ 50192 ≤ 50387 < |S|`. Equal colour ⇒ both diagonal or both pencil (else-colours are
injective on the index-tuple, and the two sinks differ), and each clique commutes by a direct
`2×2` entry computation (`Matrix.mul_apply` + `Fin.sum_univ_two` + `ring`).
