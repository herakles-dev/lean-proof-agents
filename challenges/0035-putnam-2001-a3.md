## Problem

For each integer `m`, consider `Pₘ(x) = x⁴ − (2m+4)x² + (m−2)²`. For which `m` is `Pₘ` the product
of two non-constant polynomials with integer coefficients? (Answer: `{m | ∃ k : ℤ, k² = m ∨ 2k² = m}`.)

## Formal statement

```lean
abbrev putnam_2001_a3_solution : Set ℤ := {m : ℤ | ∃ k : ℤ, k ^ 2 = m ∨ 2 * k ^ 2 = m}

theorem putnam_2001_a3
    (P : ℤ → Polynomial ℤ)
    (hP : P = fun m => X ^ 4 - C (2 * m + 4) * X ^ 2 + C ((m - 2) ^ 2)) :
    {m : ℤ | ∃ a b, P m = a * b ∧
      (∃ n ∈ Ici 1, a.coeff n ≠ 0) ∧ (∃ n ∈ Ici 1, b.coeff n ≠ 0)} = putnam_2001_a3_solution
```

## Proof

A non-constant integer factorization of the (monic, degree-4) `Pₘ` is into two degree-2 factors;
a `natDegree ≤ 2` integer polynomial is determined by its first three coefficients
(`p = C c₀ + C c₁·X + C c₂·X²`), so matching coefficients reduces factorability to an integer
condition equivalent to `m = k²` or `2k² = m`. The two arithmetic obstructions are discharged by
infinite descent over ℤ: `s² = 2r² ⇒ r = 0` (strong induction on `r.natAbs`, the classic √2
argument) and `d² = 32m ⇒ ∃ k, m = 2k²` (three rounds of "even square ⇒ even base").
