## Problem

**Source:** PutnamBench `putnam_1988_b2` (trishullab/PutnamBench, Apache-2.0). No Mathlib
`Archive` formalization exists.

For all reals $x, y$: if $y \ge 0$ and $y(y+1) \le (x+1)^2$, then $y(y-1) \le x^2$.

Ground-truth answer to the prove-or-disprove: **True**.

## Formal statement

```lean
abbrev putnam_1988_b2_solution : Prop := True

theorem putnam_1988_b2 :
    (∀ x y : ℝ, (y ≥ 0 ∧ y * (y + 1) ≤ (x + 1) ^ 2) → (y * (y - 1) ≤ x ^ 2))
      ↔ putnam_1988_b2_solution
```

## Notes

- **Not a one-line `nlinarith`.** The natural human proof is a case split (this is not a global
  degree-2 SOS certificate over the raw hypotheses — the "hard" branches need a genuine
  root/monotonicity argument), so the Lean proof case-splits the same way:
  1. `y ≤ 1`: `y*(y-1) ≤ 0 ≤ x^2` trivially (`nlinarith` with `sq_nonneg x` and
     `mul_nonneg hy (1 - y ≥ 0)`).
  2. `y > 1` and `x ≥ -1`: `nlinarith` closes it given `sq_nonneg` hints on `x - y`, `x + y`,
     `x - y + 1`, `x + 1 - y`, `2x - 2y + 1`, `2y - 2x - 1`, plus the product
     `(x+1)(y-1) ≥ 0`.
  3. `y > 1` and `x < -1`: symmetric branch, `nlinarith` with `sq_nonneg (x+y+1)`,
     `sq_nonneg (x-y-1)`, `sq_nonneg (2x+2y+1)`, and `(-x-1)(y-1) ≥ 0`.
- `rw [iff_true]` first collapses the `↔ True` to the bare `∀`-statement.
