## Problem

The real sequence `(aₙ)` satisfies `a₁ = 1, a₂ = 2, a₃ = 24`, and for `n ≥ 4`:

```
aₙ = (6 aₙ₋₁² aₙ₋₃ − 8 aₙ₋₁ aₙ₋₂²) / (aₙ₋₂ aₙ₋₃)
```

Show that for all `n ≥ 1`, `n ∣ aₙ` (i.e. `aₙ` is an integer multiple of `n`).

Source: PutnamBench `putnam_1999_a6` (trishullab/PutnamBench, Apache-2.0). No Mathlib
`Archive` formalization exists for this problem.

## Formal statement

```lean
theorem putnam_1999_a6
    (a : ℤ → ℝ)
    (ha1 : a 1 = 1) (ha2 : a 2 = 2) (ha3 : a 3 = 24)
    (hange4 : ∀ n : ℕ, n ≥ 4 →
      a n = (6 * (a (n - 1))^2 * (a (n - 3)) - 8 * (a (n - 1)) * (a (n - 2))^2)
              / (a (n - 2) * a (n - 3))) :
    ∀ n, n ≥ 1 → (∃ k : ℤ, a n = k * n)
```

## Proof idea

1. **Closed form.** `aₙ = A n := ∏_{k=1}^{n-1} 2^k (2^k - 1)`, proved by strong induction with a
   3-step lookback. The recursive step reduces (after clearing the denominators the original
   recurrence divides by) to a pure integer identity `key_id`, itself assembled from the one-step
   product recurrence `A n = A(n-1) * 2^(n-1)(2^(n-1)-1)` and the hidden linear recurrence
   `bₙ = 6bₙ₋₁ - 8bₙ₋₂` for `bⱼ := 2^j(2^j-1)` (roots 2, 4 of the original division step).
2. **Divisibility `n ∣ A n`.** Proved prime-power-by-prime-power via
   `Nat.ordProj_dvd_ordProj_iff_dvd`: for `p = 2`, the top factor `2^(n-1)` already carries enough
   powers of 2 (bounded via `Nat.factorization_lt`); for odd `p`, Euler's theorem
   (`Nat.ModEq.pow_totient`) places a factor `2^φ(p^e)(2^φ(p^e)-1)` inside the product range
   `[1, n-1]` (bound via `Nat.totient_lt`), and `p^e ∣ 2^φ(p^e) - 1` by Euler.
3. Glue: `aₙ = A n` and `n ∣ A n` give the witness `k := A n / n`.

closed form").
