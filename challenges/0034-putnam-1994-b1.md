## Problem

Find all positive integers `n` that are within `250` of exactly `15` perfect squares.
(Answer: `315 ≤ n ≤ 325` or `332 ≤ n ≤ 350`.)

## Formal statement

```lean
abbrev putnam_1994_b1_solution : Set ℤ :=
  {n : ℤ | (315 ≤ n ∧ n ≤ 325) ∨ (332 ≤ n ∧ n ≤ 350)}

theorem putnam_1994_b1 (n : ℤ) :
    n ∈ putnam_1994_b1_solution ↔
    (0 < n ∧ {m : ℕ | |n - m ^ 2| ≤ 250}.encard = 15)
```

## Proof

Translate `|n − m²| ≤ 250` to a subtraction-free ℕ predicate `N ≤ m²+250 ∧ m² ≤ N+250`
(`N := n.toNat`), which is a `Finset.Icc lo hi` with `hi = Nat.sqrt (N+250)` and, for `N ≥ 251`,
`lo = Nat.sqrt (N−251) + 1` (via `Nat.le_sqrt'` / `Nat.eq_sqrt'`); the `N < 251` case is excluded
separately (`Nat.sqrt (N+250) ≥ Nat.sqrt 251 = 15` forces the count `≥ 16`). So `encard = 15`
reduces to `Nat.sqrt (N+250) − Nat.sqrt (N−251) = 15`. Setting `k := Nat.sqrt (N−251)`, the two
`Nat.sqrt` sandwich bounds (`Nat.sqrt_le'`, `Nat.lt_succ_sqrt'`) fed to `nlinarith` pin `k ∈ {8,9}`,
then `interval_cases k <;> omega` pins `N` to exactly `[315,325]` (k=8) or `[332,350]` (k=9).
