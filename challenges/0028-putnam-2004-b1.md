## Problem

Let `P(x) = c_n x^n + c_{n-1} x^{n-1} + ... + c_0` be a polynomial with integer coefficients.
Suppose that `r` is a rational number such that `P(r) = 0`. Show that the `n` numbers

`c_n r, c_n r^2 + c_{n-1} r, c_n r^3 + c_{n-1} r^2 + c_{n-2} r, ..., c_n r^n + c_{n-1} r^{n-1} + ... + c_1 r`

are all integers. (PutnamBench `putnam_2004_b1`; no existing Mathlib `Archive` formalization —
an unaided, harder ceiling-test target.)

## Formal statement

```lean
theorem putnam_2004_b1
    (n : ℕ) (P : Polynomial ℤ) (r : ℚ)
    (Pdeg : P.degree = n)
    (Preq0 : Polynomial.aeval r P = 0) :
    ∀ i ∈ Finset.range n, ∃ m : ℤ,
      m = ∑ j ∈ Finset.range (i + 1), (P.coeff (n - j) * r ^ (i + 1 - j))
```

## Notes

DEPTH-loop solve (`proof-strategist` plan + ledger (not committed), assembled by
`lean-prover`, all leaves closed in two build iterations). Write `r = p/q` with `p := r.num`,
`q := (r.den : ℤ)` coprime.

1. **`term_cast` helper** (reused for both the root equation and the Horner sum): for `k ≤ m`,
   `(c : ℚ) * (p/q)^k * q^m = ((c * p^k * q^(m-k) : ℤ) : ℚ)`, via `div_pow` + `pow_add` +
   `field_simp`. This clears denominators uniformly.
2. **`sgA`** — clear denominators in `aeval r P = 0` (via `Polynomial.aeval_eq_sum_range` and
   `term_cast`) to get the integer identity `∑_{k≤n} c_k p^k q^{n-k} = 0`.
3. **`crux_dvd` (the hard leaf)** — split `range (n+1)` into head `range (n-i)` / tail
   `Ico (n-i) (n+1)` via `Finset.sum_Ico_consecutive`; reindex the tail against
   `range (i+1)` via `Finset.sum_nbij'` (forward/backward map `j ↦ n - j`) to show
   `p^{n-1-i} * A_i` equals (the negative of) the head sum, each of whose terms is divisible by
   `q^{i+1}` (`pow_dvd_pow` on the `q`-exponent + `Finset.dvd_sum`), where
   `A_i := ∑_{j≤i} c_{n-j} p^{i+1-j} q^j`.
4. **`sgD`** — peel off the coprime factor: `Rat.isCoprime_num_den` gives `IsCoprime p q`;
   `IsCoprime.pow` + `IsCoprime.dvd_of_dvd_mul_left` turn `q^{i+1} ∣ p^{n-1-i} * A_i` into
   `q^{i+1} ∣ A_i`, giving the integer witness `m` with `A_i = q^{i+1} * m`.
5. **`sgB` + assembly** — `term_cast` again relates the rational Horner sum `s_i` to `A_i` via
   `s_i * q^{i+1} = (A_i : ℚ)`; combined with step 4 and `mul_right_cancel₀`, `s_i = m`.
