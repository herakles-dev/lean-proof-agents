## Problem

How many positive integers `n` are an exact divisor of at least one of `10⁴⁰`, `20³⁰`?
(Answer: **2301**.)

## Formal statement

```lean
abbrev putnam_1983_a1_solution : ℕ := 2301

theorem putnam_1983_a1 :
    {n : ℤ | n > 0 ∧ (n ∣ 10 ^ 40 ∨ n ∣ 20 ^ 30)}.encard = putnam_1983_a1_solution
```

## Proof

Factor `10⁴⁰ = 2⁴⁰·5⁴⁰` and `20³⁰ = 2⁶⁰·5³⁰`. Divisor counts via `Nat.Coprime.card_divisors_mul`
+ `Nat.divisors_prime_pow` (card = exponent + 1): `|div(10⁴⁰)| = 41·41 = 1681`,
`|div(20³⁰)| = 61·31 = 1891`. The intersection is the divisor set of
`gcd(10⁴⁰, 20³⁰) = 2⁴⁰·5³⁰` (via `Nat.gcd_mul_left` after extracting the common factor), of size
`41·31 = 1271`. Inclusion–exclusion (`Finset.card_union_add_card_inter` + `omega`):
`1681 + 1891 − 1271 = 2301`. The ℤ statement is bridged to this ℕ `Finset` count by rewriting the
solution set as the `Nat.cast` image of the union (`n ↦ n.natAbs`, `Int.dvd_natCast`,
`Int.natAbs_of_nonneg`) and applying `Function.Injective.encard_image` +
`Set.encard_coe_eq_coe_finsetCard`.
